# 业务 Skill 编写指南

业务 Skill 用来把业务背景、页面入口、术语含义、操作规则和可观察断言信号补给执行模型。它适合沉淀“老用例描述太抽象，但业务侧知道怎么操作”的知识，例如 `LLL 腔室`、`Stick 流气`、`Online 状态切换` 等。

## 使用原则

- **Skill 写业务背景和通用规则**：入口路径、术语含义、状态判断、随机选择规则、等待条件。
- **用例写本次要做什么**：不要把具体测试数据、一次性步骤全部塞进 Skill。
- **面向视觉执行模型**：所有描述尽量落到页面可见对象、按钮、区域、文案、颜色、数值或列表变化。
- **不要编造信息**：资料里没有但影响执行/断言的信息，放到“待补充信息”。
- **优先可观察断言**：有状态文字时优先状态文字，颜色只作为补充信号。

## 让 Agent 编写 Skill 的 Prompt 模板

把下面模板发给 Agent，并在 `业务资料` 中粘贴业务说明、页面路径、术语解释、典型用例、截图描述或试点反馈。

输出格式必须包含：
1. Skill 名称
2. Skill 简述
3. Skill 正文

写作要求：
- Skill 名称要短，建议使用“业务域 + 操作指南”，例如：LLL腔室操作指南。
- Skill 简述要用于触发加载，必须包含关键词、页面名、业务动作。
- Skill 正文要面向执行模型，不要写成培训材料。
- 每条规则都要尽量落到页面可见对象、按钮、区域、状态、文案、颜色、数值。
- 对“任意”“随机”“随便选择”这类描述，要给出确定性选择规则。

- 禁止编造业务信息；资料里没有的信息写到“待补充信息”。
- 不要输出代码。
- 不要自动改写用例，只输出 Skill。

## 可选强化约束

如果业务资料比较抽象，可以在 Prompt 末尾追加：

```text
请站在“视觉执行 Agent 只能看页面截图和可访问文本”的角度写 Skill，所有建议都必须能被页面观察或操作验证。
```

## Skill 示例

```text
# Skill 名称
LLL腔室操作指南

# Skill 简述
当用例涉及 LLL、LLR、腔室、Online、Offline、流气、Stick流气 时加载，说明腔室入口、状态切换和可观察断言方式。

# Skill 正文

## 适用范围
- 关键词：LLL、LLR、腔室、Online、Offline、流气、Stick流气
- 页面/模块：设备工艺图、腔室状态面板
- 业务动作：进入腔室、切换在线状态、启动或停止流气

## 业务术语解释
- LLL 腔室：页面工艺图中的 Load Lock 左侧腔室区域，通常显示为带有腔室名称和状态的可点击区域。
- Online：腔室处于在线可用状态，页面上通常表现为状态文字 `Online`，可能伴随绿色状态灯。
- Stick 流气：页面上标识为 Stick 或 Stick Gas 的流气控制对象，可能表现为按钮、阀门图标或状态行。

## 标准入口路径
1. 从首页进入设备监控或工艺图页面。
2. 选择目标设备后，等待页面出现腔室区域和设备状态信息。
3. 找到标识为 LLL 或 Load Lock 的腔室区域。

## 标准操作规则
### 场景：进入 LLL 腔室
1. 在工艺图或腔室列表中找到 LLL / Load Lock 区域。
2. 点击该腔室区域或名称。
3. 等待右侧或弹窗显示该腔室详情，页面应能看到腔室名称、状态和操作按钮。

### 场景：切换腔室 Online
1. 在腔室详情区域找到状态切换按钮或 Online 按钮。
2. 点击 Online / 上线 / Enable 类按钮。
3. 等待腔室状态字段从 Offline 或 Idle 变为 Online。

## 随机/任意选择规则
当用例出现“任意 Stick 流气”时：
1. 优先选择当前页面可见、状态为可操作或关闭状态的 Stick 流气对象。
2. 多个对象都可用时，选择列表或页面从上到下、从左到右的第一个。
3. 不要选择禁用、报警、Offline 或灰色不可点击对象。
4. 执行后记录实际选择的 Stick 名称或编号，用于后续断言。

## 可观察断言信号
- 文案：页面显示 `Online`、`Enabled`、`Started` 或成功提示。
- 状态：腔室状态字段变为 `Online`。
- 颜色：状态灯变为绿色可作为补充；如果同时有状态文字，优先使用状态文字。
- 数值：如果页面有流量值，确认流量从 0 变为非 0 或进入目标范围。
- 列表/表格：操作日志新增一条对应腔室或 Stick 的操作记录。

## 等待规则
- 状态切换后最多等待 60 秒，直到腔室状态变为 Online。
- 流气启动后最多等待 60 秒，直到状态或流量值发生变化。
- 超时后判定失败，不要持续重复点击按钮。

## 禁止动作 / 风险控制
- 不要点击 Reset、Emergency Stop、Delete 等危险按钮。
- 不要在没有确认目标腔室的情况下点击相邻腔室。
- 不要只凭后台处理完成判断成功，必须看到页面可见状态变化。

## 待补充信息
- LLL 腔室在真实系统中的准确页面入口。
- Stick 流气对象的页面命名规则和可操作状态标识。
```
