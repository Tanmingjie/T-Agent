# 新用户快速接入指南（简洁版）

本指南用于新用户在 Linux 内网环境中快速启动 T-Agent，并完成第一次 Midscene 用例执行。

## 1. 环境要求

- Python 3.11+
- Node.js 18+
- Chromium 或 Chrome
- 可访问的文本模型和视觉模型服务

## 2. 安装依赖

在项目根目录执行：

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

npm install --ignore-scripts --cache .npm-cache
cd frontend
npm install
cd ..
```

Midscene 集成后，根目录的 `npm install` 是必须的：它安装 Node 侧执行器依赖，包括 `@midscene/web`、`playwright`、`@playwright/test`。`frontend/npm install` 只负责前端控制台，不能替代根目录依赖。

如果是旧环境升级，拉取新代码后至少在项目根目录补跑：

```bash
source .venv/bin/activate
pip install -r requirements.txt
npm install --ignore-scripts --cache .npm-cache
alembic upgrade head
```

`alembic upgrade head` 会创建或更新数据库结构。升级到成功经验复用版本时,会新增 `case_execution_memory` 表,并给队列执行表增加重新翻译字段。历史用例和执行记录不需要人工迁移;新版本上线后,用例再次执行且结果 PASS 时才会自动沉淀成功经验。

前端锁文件变化时再执行：

```bash
cd frontend
npm install
cd ..
```

安装 Playwright 浏览器；内网无法下载时可使用服务器上已有的 Chrome：

```bash
npx playwright install chromium
```

## 3. 配置模型

复制配置模板：

```bash
cp .env.example .env
```

至少填写以下配置：

```dotenv
LLM_MODEL=openai/your-text-model
LLM_API_BASE=http://your-llm-gateway/v1
LLM_API_KEY=your-key

MIDSCENE_MODEL_NAME=your-vision-model
MIDSCENE_MODEL_BASE_URL=http://your-vision-gateway/v1
MIDSCENE_MODEL_API_KEY=your-key
MIDSCENE_MODEL_FAMILY=qwen3.5
```

使用服务器已有 Chrome 时增加：

```dotenv
MIDSCENE_BROWSER_EXECUTABLE=/absolute/path/to/chrome
```

## 4. 初始化数据库

```bash
source .venv/bin/activate
alembic upgrade head
```

## 5. 后台启动前后端

在项目根目录执行：

```bash
mkdir -p storage/logs

HOST=0.0.0.0 PORT=8000 \
nohup .venv/bin/python scripts/serve.py \
> storage/logs/backend.log 2>&1 < /dev/null &
echo $! > storage/backend.pid

cd frontend
nohup npm run dev -- --host 0.0.0.0 --port 5173 \
> ../storage/logs/frontend.log 2>&1 < /dev/null &
echo $! > ../storage/frontend.pid
cd ..
```

访问地址：

```text
前端：http://服务器IP:5173
后端健康检查：http://服务器IP:8000/health
```

## 6. 执行第一个用例

1. 打开前端并进入测试任务。
2. 上传符合模板的 Excel 用例。
3. 未勾选用例时点击“执行全部”；勾选后点击“执行所选 N 条”。
4. 按需选择 Skill 和“人工确认执行规格”。
5. 执行后在用例列表查看进度，在“执行历史”和“报告”中查看结果。

如 Suite 配置了登录准备用例，执行业务用例时会自动先登录，并在本次 Run 内复用临时登录状态。

用例 PASS 后会自动保存“成功经验”。同一用例内容未变化时,后续执行会优先复用成功 TestSpec,并注入上次总结的操作经验。需要重新生成 TestSpec 时,在执行确认弹框打开“本次重新翻译”；需要停用某条经验时,在用例详情抽屉的“成功经验”中禁用。

## 7. 日志和停止命令

```bash
# 查看日志
tail -f storage/logs/backend.log
tail -f storage/logs/frontend.log

# 检查端口
ss -lntp | grep -E ':8000|:5173'

# 停止服务
kill "$(cat storage/backend.pid)"
kill "$(cat storage/frontend.pid)"
```

Midscene 执行产物位于：

```text
storage/midscene/<run_id>/<case_id>/
```

## 8. 常见问题

- 只能本机访问：确认启动参数包含 `--host 0.0.0.0`，并放通 `5173`、`8000` 端口。
- 浏览器不存在：执行 `npx playwright install chromium`，或配置 `MIDSCENE_BROWSER_EXECUTABLE`。
- 页面访问超时：先在服务器上用 `curl` 检查目标系统是否可访问。
- 翻译成功但执行失败：检查视觉模型配置、浏览器依赖及 `storage/midscene` 下的 runner 日志。
- SSH 退出后服务停止：确认使用了 `nohup ... &`，并检查对应日志。

完整配置项和高级用法以项目根目录的 `.env.example` 与 `README.md` 为准。
